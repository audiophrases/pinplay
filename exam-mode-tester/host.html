The Chromebook can't open the address?
  1. Windows firewall. The first time, Windows asks whether Node.js may use the network. Tick Private networks and click Allow. If you missed it: Start → "Allow an app through Windows Firewall" → find Node.js → tick Private (and Public if your Wi-Fi is set as public).
  2. Same network. Both machines must be on the same Wi-Fi. School Wi-Fi often blocks devices from talking to each other. If so, on this laptop turn on Settings → Network → Mobile hotspot, connect the Chromebook to that hotspot, and reload this page: the hotspot address (192.168.137.1) appears above.
  3. Blocked sites. If the student account blocks the address, sign in to the Chromebook with another account. The lock key behaves the same, since ChromeOS handles it, not the account.
  4. Type the address exactly, starting with http:// (not https).
