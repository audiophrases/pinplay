🎙️ PinPlay Listening Studio

    Make a listening recording

    Paste a recording script (from PinPlay's 📋 Copy script, or from the ✨ Script prompt), or any text: plain text is read by one voice. The studio starts at once.

    🎛️ Set up the recording

    Your script has no settings yet. Choose them here: they are added to the top of your script, and your words are not changed. Or let an AI do it: ✨ Script prompt → Voices and directions for my script.

    🎭 Voices

    Each character's voice. Fixed voice keeps it exactly the same on every line (the default); Acted performs each line's direction, but the voice can vary a little. To change a voice, edit its description and press ↻ Remake voice.
