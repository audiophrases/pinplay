🎙️ PinPlay Listening Studio

    Make a listening recording

    Paste a recording script (from PinPlay's 📋 Copy script, or from the ✨ Script prompt), or any text: plain text is read by one voice. The studio starts at once.

    🔊 The recording

    🎭 Voices

    Each character's voice. Fixed voice keeps it exactly the same on every line (the default); Acted performs each line's direction, but the voice can vary a little. A new voice sample remakes that character's lines.

    💬 Lines

    🎚️ Settings

    Only what changed is made again.

    📝 Script

    ✨ Script prompt

    Instructions for an AI chatbot to write a recording script the studio can make with no changes. Paste the AI's answer into a new recording.
